# 👻 Specter: sonar for your iPhone

**Every ghost-hunting app is fake. Specter senses the air for real.**

Specter turns an iPhone's speaker and microphone into an inaudible sonar. It tracks breathing and movement near the phone using sound you can't hear. No camera. No internet. Nothing leaves the device.

## What it does

- **Live breathing tracking:** waveform, breaths per minute and confidence
- **Movement alerts:** a bold banner when something moves near the phone
- **Breath hold detection:** the orb freezes when breathing stops
- **Private by design:** all processing runs on the device

## How it works

1. The phone plays a repeating chirp sweeping 18–21 kHz, with a period of 512 samples at 48 kHz.
2. The microphone records the direct sound plus echoes.
3. Cross-correlating any 512-sample window with the chirp gives the room's echo profile. Because the signal is periodic, no clock alignment is needed.
4. Static echoes are removed with a moving average.
5. The phase of the strongest moving echo gives chest displacement:

   `displacement = -phase × wavelength / (4π)`  (about 1.4 mm per radian at 19.5 kHz)

6. An FFT of the last 20 seconds gives the breathing rate.

Full details are in [`docs/PHYSICS.md`](docs/PHYSICS.md).

## Run it

**Requirements:** a Mac with Xcode, an iPhone running iOS 16+, Python 3.11+.

```bash
# Python reference and property tests
cd lab
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q

# Swift core tests (includes golden vectors generated by the Python lab)
cd ../core/SpecterCore
swift test
```

**On your iPhone:** open `app/Specter/Specter.xcodeproj`, select your phone, and run. Allow microphone access. Place the phone upright on a table, 0.3–0.8 m from your chest, at moderate volume.

## Honest limits

- Measures **distance and motion, not direction**
- Works best at about 0.3–1 m
- Large body movement hides breathing
- Soft furnishings absorb ultrasound
- Some people and pets may notice ultrasound. Use a low volume and monitor only people who know about it.
- Results depend on your iPhone's speaker and microphone

## Prior work

Phone-based sonar sensing is established research. Specter is an independent implementation and product experience built on ideas from:
